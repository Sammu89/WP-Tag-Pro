== Description ==

Whether you're managing a small blog or a large content site, this plugin streamlines your tagging workflow and improves content discoverability.

**🎯 Core Features:**

* **Intelligent Content Analysis**: Advanced algorithms scan post titles and content to identify relevant keywords and phrases
* **Tag Family System**: Create organized groups of related tags for consistent tagging across your site
* **Automatic Year Tagging**: Automatically add year-based tags for chronological content organization
* **Existing Tags Integration**: Seamlessly works with your current WordPress tag system - no disruption to existing workflows  
* **Bulk Processing**: Process thousands of existing posts at once with memory-optimized batch processing
* **Custom Post Types Support**: Works with posts, pages, and custom post types
* **Multiple Taxonomy Support**: Compatible with tags, categories, and custom taxonomies

== Installation ==

**Automatic Installation (Recommended):**
1. Log in to your WordPress admin dashboard
2. Navigate to Plugins > Add New
3. Search for "WordPress Auto-Tag Pro"  
4. Click "Install Now" and then "Activate"

**Manual Installation:**
1. Download the plugin ZIP file
2. Upload the plugin files to the `/wp-content/plugins/wp-auto-tag-pro` directory, or install through the WordPress plugins screen
3. Activate the plugin through the 'Plugins' screen in WordPress

**Getting Started:**
1. Navigate to Settings > Auto-Tag Pro in your WordPress admin
2. Configure your basic settings (post types, taxonomies, content areas to analyze)
3. Set up tag families if desired for organized tagging
4. Test with a few posts to ensure proper operation
5. Use bulk processing to tag existing content, or enable automatic tagging for new posts

**System Requirements:**
- WordPress 5.0 or higher
- PHP 7.4 or higher
- Recommended: 128MB+ PHP memory limit for bulk processing

== Frequently Asked Questions ==

= How does the automatic tagging work? =

The plugin uses advanced content analysis algorithms to scan your post titles and content, identifying relevant keywords and phrases. It then matches these against your configured tag families, existing WordPress tags, and built-in keyword databases to automatically apply the most relevant tags. You can choose between classic keyword matching and tag family systems for maximum flexibility.

= Can I use this with existing tags? =

Absolutely! WordPress Auto-Tag Pro integrates seamlessly with your existing WordPress tag system. It can work alongside your current tags, respect manual tags you've already applied, and even learn from your existing tagging patterns to improve suggestions. You can choose to merge new tags with existing ones or replace them entirely.

= Does this work with large websites? =

Yes, the plugin is specifically designed for large-scale deployments. It includes advanced memory management, efficient caching systems, and intelligent bulk processing that can handle thousands of posts without overwhelming your server. Bulk operations are automatically batched and can be paused/resumed as needed.

= Can I customize which tags are applied? =

Definitely! You have full control over the tagging process:
- Configure which post types and taxonomies to target
- Set up custom tag families with related keywords
- Define matching criteria and case sensitivity
- Choose which content areas to analyze (title, content, excerpts)
- Create exclusion rules for specific posts or content types
- Set processing limits and batch sizes

= Does this affect my site's performance? =

WordPress Auto-Tag Pro is optimized for minimal performance impact:
- Efficient caching reduces database queries
- Memory management prevents timeouts during bulk processing
- Automatic tagging for new posts adds minimal overhead to publishing
- Bulk processing can be scheduled during off-peak hours
- Built-in monitoring helps track resource usage

= Is it compatible with custom post types and taxonomies? =

Yes! The plugin works with any custom post type that supports the taxonomies you want to tag. It's compatible with custom taxonomies beyond just tags and categories, making it perfect for complex content structures, e-commerce sites, and specialized WordPress installations.

= Can I undo automatic tagging? =

The plugin tracks its tagging activities, allowing you to identify which tags were added automatically. While there's no single "undo all" button, you can use the bulk processing tools to remove tags based on specific criteria or timeframes. Always test on a staging site first for major changes.

= How do I migrate from another tagging plugin? =

WordPress Auto-Tag Pro can work alongside other tagging solutions. Start by configuring the plugin to match your existing tagging patterns, then gradually transition by enabling automatic tagging for new content while leaving existing tags intact. The tag family system can help maintain consistency during migration.

= Does it work with WordPress Multisite? =

Yes, WordPress Auto-Tag Pro is fully compatible with WordPress Multisite networks. You can configure settings per site or use network-wide configurations as needed. The plugin respects WordPress Multisite permissions and can be network-activated or activated per-site.

= What if I encounter issues or need support? =

Check the plugin's status page in your WordPress admin for system health information and troubleshooting tips. The plugin includes comprehensive error logging when WordPress debug mode is enabled. For additional support, refer to the plugin documentation or contact support through the official channels.

== Privacy Policy ==

WordPress Auto-Tag Pro processes post content locally on your server to analyze and suggest tags. The plugin does not transmit any content or data to external servers. All processing happens within your WordPress installation.

**Data Collected:**
- Post content for analysis (processed locally only)
- Plugin usage statistics (stored locally)
- Processing logs and error reports (stored locally)
- User configuration preferences (stored locally)

**Data Storage:**
All data is stored in your WordPress database and is subject to your site's existing privacy policy and data retention practices.

**Data Sharing:**
No data is shared with third parties. All processing is performed locally on your server.
